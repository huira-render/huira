# 01 - First render

A sphere lit by the Sun, seen by a camera: the smallest complete scene, and the steps that every render takes.

![01 - First render](https://media.huira.space/examples/01_first_render.png)

## Data

None: everything in it is built in code.

## Run

From this folder, in Python:

```bash
python first_render.py
```

or in C++, built as in [Running the examples](../README.md#c):

```bash
../../build/01_first_render
```

Each writes its images to `output/`, in the folder it runs from.
