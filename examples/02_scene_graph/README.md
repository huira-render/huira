# 02 - Scene graph

A small scene graph: assets shared between primitives and instances, frames that carry what is in them, rotations and scale, a mesh built in code, and a camera pointed with `look_at`.

![02 - Scene graph](https://media.huira.space/examples/02_scene_graph.png)

## Data

None: everything in it is built in code.

## Run

From this folder, in Python:

```bash
python scene_graph.py
```

or in C++, built as in [Running the examples](../README.md#c):

```bash
../../build/02_scene_graph
```

Each writes its images to `output/`, in the folder it runs from.
