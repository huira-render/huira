# 08 - Lights

Red, green and blue sphere lights over three spheres, where the colors of the shadows show light adding up, and planetshine: a satellite's night side, lit by the planet below it as an indirect source.

| Colored lights | Planetshine |
|:--------------:|:-----------:|
| ![08 - Colored lights](https://media.huira.space/examples/08_lights.png) | ![08 - Planetshine](https://media.huira.space/examples/08_lights_planetshine.png) |

## Data

None: everything in it is built in code.

## Run

From this folder, in Python:

```bash
python lights.py
```

or in C++, built as in [Running the examples](../README.md#c):

```bash
../../build/08_lights
```

Each writes its images to `output/`, in the folder it runs from.
