# 05 - Planetary BRDFs

Huira's BSDFs for planetary surfaces side by side, at a 90 degree phase angle and near opposition.

| Planetary BRDFs at 90 degree Phase |
|:-:|
| ![05 - Planetary BRDFs](https://media.huira.space/examples/05_planetary_brdfs.png) |
| Planetary BRDFs as Opposition |
| ![05 - Planetary BRDFs Opposition](https://media.huira.space/examples/05_planetary_brdfs_opposition.png) |

Lambertian, Oren-Nayar, Lommel-Seeliger, McEwen, and Hapke BRDFs at various phase angles.


## Data

None: everything in it is built in code.

## Run

From this folder, in Python:

```bash
python planetary_brdfs.py
```

or in C++, built as in [Running the examples](../README.md#c):

```bash
../../build/05_planetary_brdfs
```

Each writes its images to `output/`, in the folder it runs from.
